Aladdin Interface Requirements

Advisory Reference Model
MODEL_INFO New
File sent to Aladdin
  • ID — Model ID used to identify the model. Must be consistent between MODEL_INFO.ID and MODEL_POSITION_DATA.PORTFOLIO_ID.
  • NAME — Name of the model portfolio, reflected in the front end.
  • CURRENCY — Currency of the model portfolio.
  • MODEL_TYPE — Value must be set to 'Model'.
  • FAMILY — Grouping name displayed in the front end.
MODEL_POSITION_DATA
File sent to Aladdin
  • POS_DATE — Date of the file.
  • PORTFOLIO_ID — ID of the model. Must match MODEL_INFO.ID.
  • CLIENT_ID — CLIENT_ID of the corresponding security found in the SECURITY_MASTER file.
  • WEIGHT — Weight of the position. Total weight across all positions must sum to 1.
